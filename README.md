# ULP Tech – Formación tecnológica

Sitio web de la propuesta de extensión de la Universidad de La Punta: presenta cursos y charlas de tecnología y permite pre-inscribirse mediante un formulario.

Trabajo Final Integrador – Programación Web 1 – 2026.

## Autores

- Gonzalo Martin Asis
- Jessica Auriol

## Sitio publicado

https://gonzamartin91.github.io/Examen-Integrador-Web1/

## Páginas

- **Inicio** (`index.html`): presentación del sitio y carrusel de cursos destacados.
- **Cursos y charlas** (`contenido.html`): propuestas organizadas en tres columnas con Flexbox y agenda con fechas.
- **Inscripción** (`contacto.html`): formulario con validación en JavaScript y resumen de los datos enviados.

## Instrucciones de uso

1. Ingresar al sitio publicado o abrir `index.html` en el navegador.
2. Navegar entre las páginas con el menú superior (en celulares se abre con el botón ☰).
3. En el carrusel, usar las flechas ‹ › para recorrer los cursos y el botón **VER** para ir al detalle.
4. En **Inscripción**, completar el formulario: si hay errores se muestran debajo de cada campo; si los datos son válidos, aparece un resumen de la inscripción.

## Tecnologías

- HTML5 semántico
- CSS3 (Flexbox, variables CSS y media queries), sin frameworks
- JavaScript, sin librerías
